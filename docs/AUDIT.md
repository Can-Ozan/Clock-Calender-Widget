# v2.0 repository audit

Audited all tracked source, HTML, CSS, configuration, documentation, lockfile and generated `dist/` files before implementation on 13 September 2026. The starting working tree was clean.

| Area          | Finding                                                                                                                                                                                  | Resolution planned                                                                                                                                                                     |
| ------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Clock         | `toggleTimeFormat()` only changes the AM/PM suffix; hours remain 00–23. No visible control.                                                                                              | One Intl formatter with explicit h12/h23 cycles and persisted controls.                                                                                                                |
| Dates         | Day-of-year and days remaining subtract local timestamps, making results sensitive to time of day and DST. Week numbers are not ISO-8601.                                                | Gregorian civil-date arithmetic using UTC day ordinals; ISO week-year tests.                                                                                                           |
| Calendar      | Adjacent dates can be selected without changing month. Selection only logs to console.                                                                                                   | Navigate on selection and update date details/events.                                                                                                                                  |
| Accessibility | Clickable divs, unlabeled icon buttons, no calendar roles or keyboard operation, no reduced-motion support. Some muted colors fail contrast.                                             | Native buttons, grid semantics, roving focus, reduced motion and accessible colors.                                                                                                    |
| Lifecycle     | Repeated `start()` creates multiple intervals; `stop()` retains its ID. DOM references and statistics are refreshed every second, even in hidden tabs.                                   | One aligned, visibility-aware timeout with cached elements and cleanup.                                                                                                                |
| Storage       | Only theme is saved. Unguarded localStorage can throw and prevent startup.                                                                                                               | Versioned, validated stores with recoverable failure messages and legacy theme migration.                                                                                              |
| TypeScript    | Strict mode is off. Build only invokes Vite, so it does not typecheck.                                                                                                                   | Strict configuration, explicit interfaces, build-time checking.                                                                                                                        |
| Tooling       | Lockfile contains Vite 5.4.21, TypeScript 5.9.3; no tests, lint, format or CI.                                                                                                           | Supported Vite 8, compatible stable TypeScript, Vitest, ESLint, Prettier and CI.                                                                                                       |
| Layout        | 440px maximum card and heavily nested padding waste desktop space and compress 320px layouts.                                                                                            | Two-column desktop layout and single-column mobile with verified widths.                                                                                                               |
| Assets/PWA    | External Google font, no icons, manifest or offline support.                                                                                                                             | System fonts, local icons and a versioned precache service worker.                                                                                                                     |
| Repository    | No .gitignore; generated dist is tracked without a deployment requirement.                                                                                                               | Ignore build output and remove its tracking, keeping source intact.                                                                                                                    |
| HTML          | Generic Turkish title, no description/social metadata, no main landmark.                                                                                                                 | Meaningful metadata and semantic content; retain Turkish via language preference.                                                                                                      |
| README        | Broken screenshot markup points to a webpage, wrong clone directory and issue link, Node 16 recommendation incompatible even with Vite 5, unsupported claims about checking/source maps. | Document only verified v2 behavior and include a real screenshot.                                                                                                                      |
| Deployment    | The old README's demo endpoint returned HTTP 404. There was no hosting configuration.                                                                                                    | Per the user's revised scope, remove the broken link and draft provider-specific configuration. Validate locally and document platform-neutral static hosting; no deployment required. |

The existing four-class/module architecture is small and suitable. Keep `main.ts`, `Clock.ts`, `Calendar.ts` and `DateUtils.ts`; add focused components and stores instead of introducing a framework. Existing month generation, Monday-first behavior, today navigation and theme preferences are retained and strengthened.

Dependency versions and engine/peer ranges were checked against the npm registry. Vite's Node requirements were also checked against its [official release notes](https://vite.dev/blog/announcing-vite8). TypeScript is selected to remain within typescript-eslint's supported peer range; upgrading to an incompatible latest major would defeat reliable linting.
